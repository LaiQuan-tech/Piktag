## 一、三條鐵律(所有方案的邊界)

1. **Sponsored ≠ Organic,永不混排。** 任何付費曝光都住在獨立、明確標示
   的區塊;自然排序(搜尋、媒合、推薦)一根手指都不能碰。Google
   2010-2020 的教訓:廣告蠶食自然結果,「找到對的人」退化成「找到付錢
   的人」—— PikTag 的護城河是搜尋信任,信任死則論文死。
2. **先論文,後變現。** 「第 3 個月變現,會殺死讓第 24 個月變現有價值的
   唯一信號。」每個方案都掛數據門檻,冷啟動期只累積資料原語
   (曝光記錄、query_id、dismissals、品質分素材 —— 已在累積),不開賣。
3. **控制權是賣點。** 免費層 = 系統與社群的好預設(社群 pick 排序、系統
   發起的批次 cohort)**加上截至 2026-09-09 已出貨的手動能力
   (手選批次)**;付費層 = 使用者拿回主導權
   (置頂、**進階選人法的批次**、主動媒合)。免費層永遠完整可用,付費是升級
   不是解鎖基本功能 —— 這句管轄上面兩句:**已經免費的東西不因為想賣而收回**
   (2026-09-09 手選批次案,原寫「任選批次」屬付費,已改切)。

## 二、產品矩陣

### 1. PikTag Pro — 個人訂閱($5–8/mo,單一 SKU)

四個能力打包,不拆售、不做兩個並列 $5 訂閱:

| 能力 | 內容 | 為什麼值錢 |
|---|---|---|
| 貴人王(主動媒合) | 更高頻率、更多候選、完整「為什麼推薦你們認識」、主動引介請求 | 賣「更多核心產品」給付費者 —— 不腐蝕他人體驗、不污染標籤資料,五案最優 |
| 批次標籤(進階選人) | 條件選人(依標籤/地點/時間/未標籤者)、一次套多個標籤、整批 AI 建議標籤、匯出**選取的那一批**(全庫匯出屬 CRM 進階那列) | **界線 2026-09-09 改切**:在「怎麼選人」不在「能不能選」。**免費 = 使用者手選**(好友列表選取模式,早已出貨);付費 = 上列進階選法。系統自動提出的批次一律免費,不必逐條列。資料飛輪不變:付費者資料更豐富→他的媒合更準→貴人王更有感。(原記載「付費=任選」,探測發現手選早已免費出貨,收回去會違反本檔原則 3) |
| 標籤置頂 | 一鍵把主打標籤鎖在自己檔案第一格 | 現況他人檔案頁是 pick 動態排序(社群共識上浮);置頂=買回主導權。只影響自己頁面、零排序污染。is_pinned 機制已在排序鏈最高位,UI 早已預留為付費功能 |
| CRM 進階 | 跟進提醒排程、備註全文搜尋、聯絡人匯出、引介追蹤 | 對標 Dex $12/Clay $10-20,付費意願已被市場驗證;直接強化活化舊人脈迴圈 |

**啟動門檻(暫定,創辦人可調)**:WAU ≥500 且 週真實加好友 ≥200 且
推薦→加好友轉化 ≥10%。理由:媒合品質靠網絡密度,免費層先做到「哇」,
Pro 才不是賣空氣。

### 2. 真人認證(低價:$2–3/mo 或一次性 $10 級)

- **不是**名人藍勾。是「這是查核過的真人」信任徽章 —— PikTag 的陌生
  信任面(Ask、活動房間、二度橋樑)天生需要它,賣的是**連結轉化率**。
- 原案 $15/mo 否決:認證價值來自被冒充風險,冷啟動網絡沒有,定價錯位。
- 技術鐵律:`is_verified` 只表「真人」,絕不與「可投放廣告」共用 flag。
- 時機:Pro 上線後,或 Ask/活動房間出現信任摩擦回報。

### 3. 主辦方方案(B2B,獨立定價)

- 內容:大型活動房間、與會者名單匯出、QR 客製品牌、多場活動儀表板、
  會後分析(誰連結了誰)。
- 邏輯:活動 QR 本質是主辦方工具,買單的是有預算的公司/社群;每場活動
  都是 PikTag 的獲客引擎 —— **向企業收費,等於讓企業補貼用戶成長**,
  且完全不碰排序誠信。
- 時機:同一 host 辦 ≥3 場活動、或主辦方主動詢價。

### 4. 贊助標籤(人氣王的正確形式,創辦人核可 2026-07-06)

原案「付費保證搜尋前三(混排)」否決 —— 違反鐵律一。核可的形式:

- **獨立「贊助」區塊**:自然結果之上或之下的獨立列,永不插入自然排序。
- **明確標示**:「贊助」字樣,使用者一眼可辨。
- **限額**:每次查詢 1–2 席,不做無限貨架。
- **尊重 dismissals**:被使用者 dismiss 過的候選人,花錢也不再出現
  (這是本產品最不可侵犯的信任線)。
- **品質分把關**:低品質付費者買不到位置 —— 需要品質分素材
  (曝光×點擊×轉化×負訊號)累積成熟。
- 時機:v3 資料原語齊備(concept_user_quality view、search_users 讀
  dismissals)**且** Pro 已驗證付費意願之後。這是通往 v3 標籤拍賣的
  第一個台階,不是終點。

### 5. 商業檔案(business_profiles,未來)

- 賣車、賣房、接案者的真需求不是一根圖釘,是**商業身分**:與個人檔案
  分離的實體、曝光工具、聯絡轉化。v3 已裁決採選項 (b):獨立
  `piktag_business_profiles`,由已認證真人擁有。
- 它是贊助標籤/拍賣的「廣告主身分層」—— 個人帳號不投放,商業檔案才投放。
- 時機:置頂類「想被看到」請求累積 ≥3 起,或贊助軌道啟動前。

## 三、啟動時序

```
Phase 0(現在)   什麼都不賣。累積原語:曝光、query_id、dismissals、
                  品質分素材。監測 60-TRIGGERS #19 門檻。
Phase 1           PikTag Pro 上線(門檻達標後)。IAP,單一訂閱。
Phase 2           真人認證 + 主辦方方案(各自觸發,可並行)。
Phase 3           贊助標籤(獨立區塊)→ 商業檔案 → v3 標籤拍賣。
                  每一步都以前一步的信任與數據為地基。
```

## 四、不做清單(與做的清單同等重要)

- 付費保證自然搜尋名次(任何形式的混排)。
- ~~免費的「任選好友」批次入口~~ —— **2026-09-09 撤銷這條**。手選批次早已免費出貨(ConnectionsScreen 選取模式),而原則 3 鎖的是「免費層永遠完整可用,付費是升級不是解鎖基本功能」;把已經在用的功能收回去賣,違反的是自己的原則。付費線改切在進階選人法(見上表)。**新的不做:把手選批次改成付費。**
- $15/mo 名人式藍勾。
- 兩個並列的 $5 訂閱(選擇癱瘓、攤薄轉化)。
- 冷啟動期開賣任何東西。
- `is_verified` 兼作廣告主資格。
- 個人帳號直接投放廣告(投放走商業檔案)。
